# EQ1 V4 DESIGN BIBLE — STANDARD 1 OR 3 OUTPUT FORMAT

> Collection Creator Template v1. This is the canonical EQ1 collection-design Markdown. Replace every `[PLACEHOLDER]` before uploading it to Collection Studio, then duplicate the complete design block for each additional product.
>
> Image mode rule: every design must contain either `Image 1` only or the complete `Image 1`, `Image 2`, `Image 3` sequence. The full sequence shown below is recommended because the queue can generate either Image 1 alone or all three linked outputs from the same Markdown. Never define exactly two images or skip an image number.

## Collection
[COLLECTION NAME]

## Category
[CATEGORY, FOR EXAMPLE: Animated Series]

## Global Rules
- Garment: regular UK-cut cotton T-shirt in an approved color: Black, White, Maroon, Navy, Forest Green, or Wheat/Cream.
- EQ1 logo: place it on the wearer’s left chest at 2.5 inches, in Rubik 600 uppercase.
- Main artwork: use centered premium DTF artwork at about 65–70% of the safe print area with 2.5–3 inches of clean margin.
- Artwork: keep the visual system premium streetwear, production-safe, and built from bold connected shapes; avoid fragile floating details.
- Models: use adult Pakistani fashion models only, with clean, premium, fashion-forward styling.
- Poses: use energetic editorial poses, never stiff catalogue poses; keep the garment and artwork clearly visible.
- Background: keep the foreground sharp with a strongly blurred cinematic background.
- Output 1: show front and back flat product views in one clean 1:1 image, with no model.
- Output 2: show two models wearing the same T-shirt, one presenting the front and one presenting the back.
- Output 3: show fabric and construction details only; do not show the artwork.
- All final outputs: create exactly one square 1024 × 1024 web asset per requested output; do not create collages, watermarks, labels, or UI.
- Do not add unrequested logos, text, graphics, or accessories.
