Record exact composition, GSM, finish, and construction in the collection directory.

### Garment / Product Types
Record exact garment type in the collection directory.

### Collection Mapping

### Generation Prompts

### Production Notes
Add collection-specific manufacturing, print, fit, finishing, and color constraints as they are confirmed.

## Record Policy

This repository should preserve the design history of EQ1 collections. For each collection, record at minimum:

- date/time of creation or update
- season
- fabric specification
- approved base fabric colors
- garment/product type
- collection name and concept
- generation prompts and revisions
- relevant production constraints
- final approved design references / metadata as they become available

This file is the starting reference for the **Winter 2026 base fabric palette**.
