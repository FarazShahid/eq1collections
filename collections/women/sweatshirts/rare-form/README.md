## Collection Thesis

**Rare Form** is a selective, high-end women's sweatshirt collection built around confident color blocking, premium restraint, and a single refined embroidered focal motif on each design. The collection should feel deliberate, feminine, uncommon, and elevated rather than mass-market.

## Embroidery Direction

Each sweatshirt should carry a distinct embroidery idea built around **one focal element**, not a crowded multi-element composition.

Recovered motif examples:

- Swan
- Butterfly
- Archangel wings

Do not repeat the same focal motif across multiple designs unless intentionally approved as a collection system.

## Cut / Construction Direction

A project reference cut was specifically selected for the **Green, Yellow, and Pink** variants. The source image exists in project history, but exact pattern dimensions and cut measurements were not recoverable in the current runtime, so they are not invented here.

The design process explicitly moved forward with **cotton** as the fabric direction.

## Branding / Decoration

- Brand text should remain **EQ1** in capitals where used.
- Embroidery is the primary decorative technique recovered for this collection.
- Keep the garment premium and restrained; the focal embroidered element should remain the principal graphic statement.
