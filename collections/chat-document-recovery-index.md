## Global design rules recovered from project history

These are cross-collection instructions recovered from prior EQ1 project conversations and should be validated against the collection-specific source before use:

- `EQ1` is written in capitals.
- Anime and Original Series collections are unisex.
- Female-oriented series may use women in model-based collection imagery.
- Series-banner imagery for Anime / Original Animated Series should not include a human model or T-shirt when the image is functioning as the series banner.
- Men’s collection imagery should not use the District M design/framing treatment.
- For DTF artwork, maintain safe margins and avoid fragile thin corners and thin typography.

## Recovery workflow

When an original chat attachment or MD file is surfaced again:

1. Store the original file unchanged in the matching collection folder.
2. Preserve the original filename wherever practical.
3. Add date/time, source conversation date, fabric, garment type, colors, prompt/version notes, and production constraints to the collection record.
4. Mark this recovery index entry as `Original recovered`.
5. Do not delete the reconstructed record; retain it as provenance/audit history unless it is an exact duplicate.
