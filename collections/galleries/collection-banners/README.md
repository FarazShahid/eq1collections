## District M Banner Direction

For **Anime** and **Original Animated Series**, when the visual is being created as the **series / collection banner**:

- Do not put the artwork on a T-shirt.
- Do not include a human fashion model.
- Treat the series artwork / visual world itself as the banner subject.
- Preserve the District M visual framing / collection identity where appropriate.

This banner rule is deliberately separate from product / model imagery, where unisex garment presentation may still be used.

## Audience Rule

Anime and Original Series product collections are treated as **unisex**. Female-oriented series may use women in model-led product imagery, but that does not change the no-model rule for the series banner itself.

## Men's Collection Rule

Men's collection imagery should **not** use the District M design / framing treatment unless a later collection-specific source explicitly changes that direction.

## Source Priority

A recovered collection-specific banner master prompt overrides this shared gallery rule if it contains an explicit exception.
